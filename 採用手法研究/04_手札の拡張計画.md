# 提案手札の拡張計画

最終更新: 2026-08-13 / ステータス: v1
上位文書: `01_母集団形成の手法選定.md`

**注意：** 個別サービス名は変更・統合・終了がありうる。**提案前に必ず現存と条件を一次確認する。**
本書はサービス名の正確性ではなく、**「どの型の札が欠けているか」** の地図として使う。

---

## 1. 現在の手札の診断

| 現在の手札 | 型 |
|---|---|
| Indeed／Airワーク | 求人検索エンジン（運用型） |
| ハローワーク | 公共 |
| リクルートダイレクトスカウト／dodaダイレクト | スカウト媒体（ハイクラス〜中堅） |
| リクルートエージェント／マイナビエージェント | 人材紹介（総合大手） |
| 業界特化型エージェント | 人材紹介（特化） |

### 構造的な特徴

- **8枚すべてが A2（母集団形成）。** A1（訴求）と A4（クロージング）の札がゼロ
- **8枚すべてが「金銭を払って、待つ／推薦を受ける」型。** 工数で買う札がゼロ
- **対象セグメントが「中途・正社員・都市部」に集中。** 高卒・シニア・主婦・外国人・障がい者・アルバイト・新卒の札がゼロ
- **予算がある会社向けに偏っている。** 予算限定・無名・地方の中小に出せる札が実質2枚（ハローワーク、Indeed）

### 打席と手札のミスマッチ

中小企業の相談で最も多いのは「**予算がない・知名度がない・地方・人事は社長か兼務1人**」。
この条件で今の8枚から出せるのはハローワークとIndeedだけで、しかもその2枚は
**訴求（求人票の質）が悪いと機能しない**。つまり現状、最頻の打席に対して実質的な札がない。

## 2. 穴の優先順位

| 優先 | 欠けている札の型 | なぜ効くか |
|---|---|---|
| **1** | **訴求を作る札** | 既存8枚すべての性能を底上げする。ここが弱いと何を足しても効かない |
| **2** | **工数で買う札** | 予算がない会社に出せる唯一の通貨。打席が最も多い |
| **3** | **対象を広げる札** | 「母数」制約に効く唯一の解。他の手法では絶対に解けない |
| **4** | **制度・助成金の札** | 実質的な値引き。社長の判断要素（費用の形）に直接効く |
| 5 | 現業・アルバイト・地方の札 | 中小の実需が大きい |
| 6 | 新卒・若手の札 | 中長期の相談に応じられる |
| 7 | 既存関係からの転換の札 | 探索コストほぼゼロ |

---

## 3. 優先1：訴求を作る札（最優先・コストゼロ）

**これは手法ではなく、全手法の性能を決める上流変数。**
Indeed もハローワークもエージェントも、訴求が弱ければ機能しない。

| 札 | 内容 | 費用 |
|---|---|---|
| **求人票の書き直し** | 職務内容・訴求点・条件表記の再設計。**最もROIが高い** | ゼロ（工数のみ） |
| **採用ピッチ資料** | 会社説明・課題・カルチャーを候補者向けに整理した資料 | ゼロ〜制作費 |
| **社員インタビュー記事** | 求人票に貼る・スカウト文面に添える | ゼロ（工数のみ） |
| **無料の採用ページ作成ツール** | engage（エン・ジャパン）等。Indeed 等への連携も可 | 無料〜 |
| **求人写真の撮り直し** | 現場・人が写っている写真の有無で反応が変わる | ほぼゼロ |
| **スカウト文面の型づくり** | 既存のRDS・dodaダイレクトの返信率を直接改善する | ゼロ（工数のみ） |

> **既存手札の性能を上げる提案は、新しい費用が発生しないため社長の決裁が要らない。**
> 「まず今払っているものの効きを上げましょう」は、最も通りやすい提案になる。

---

## 4. 優先2：工数で買う札（予算がない会社への回答）

| 札 | 適合条件 | 支払う通貨 |
|---|---|---|
| **リファラル制度設計** | 社員数が一定以上／社員が自社を勧められる状態 | 社員の時間・制度運用工数 |
| **アルムナイ・出戻り** | 退職時の関係が良好 | 関係維持の工数 |
| **カジュアル面談の型づくり** | 現場が出られる | 現場の時間 |
| **タレントプールの再接触** | 過去の応募者・見送り者の蓄積がある | 運用工数 |
| **取引先・同業経由の紹介** | 社長のネットワーク | 社長の関係資本 |
| **商工会議所・業界団体の求人窓口** | 地域に根ざした企業 | 関係構築 |
| **社員のSNS発信** | 発信できる人がいる | 社員の時間 |

**リファラルは「制度を作る」だけでは動かない。** 稼働しない場合、
それは制度の問題ではなく「社員が自社を勧めたくない」状態の指標である点も含めて提案材料になる。

---

## 5. 優先3：対象を広げる札（母数制約への唯一の解）

要件を満たす人が市場にいない場合、手法をいくら変えても解けない。**市場の境界を動かすしかない。**

| 札 | 主な適合先 | 備考 |
|---|---|---|
| **高卒採用（ハローワーク経由）** | 地方の製造・建設・介護・運輸 | **最も見落とされている札。** 学校訪問・求人票提出・選考開始の年間スケジュールが決まっており、日程は年により変わるため要一次確認 |
| **専門学校・職業訓練校ルート** | 技能職・介護・IT | 学校との関係構築が前提 |
| **職業訓練（求職者支援訓練）修了者** | 未経験からの育成前提採用 | 訓練施設との接点 |
| **シニア採用** | 技能伝承・現業・短時間 | 処遇と役割の再設計が必要 |
| **主婦・パート層** | 事務・販売・介護 | 勤務時間の柔軟性が決定変数 |
| **外国人採用（在留資格・特定技能）** | 製造・介護・建設・外食 | 受け入れ体制が前提。業務と在留資格の適合確認は必須 |
| **障がい者採用** | 業務の切り出しができる企業 | 就労移行支援事業所・地域障害者職業センターが主要チャネル |
| **Uターン・Iターン／移住支援** | 地方企業 | 自治体の移住支援制度と組み合わせる |
| **自治体の無料職業紹介所** | 地方企業 | 費用ゼロ |
| **未経験・異業種からの育成前提採用** | 要件を緩める判断 | 実質的には要件変更の提案 |

## 6. 優先4：制度・助成金の札（費用の「形」を変える）

社長の判断要素は金額そのものより形。**助成金は実質的な値引きとして強く効く。**

- トライアル雇用に関する助成
- 特定の求職者の雇入れに関する助成
- 人材育成・訓練に関する助成
- 自治体独自の採用・移住支援制度

> **要件・金額・申請期限は年度ごとに変わる。本書には一切数字を書かない。**
> 提案時は必ず最新の要綱を一次情報で確認する。
> また「助成金ありきで要件を歪める」と採るべきでない人を採ることになり、CPHはむしろ悪化する。

## 7. 優先5：現業・アルバイト・地方の札

| 札 | 備考 |
|---|---|
| **求人検索エンジンの横展開**（求人ボックス、スタンバイ 等） | Indeed の運用スキルがそのまま転用できる。**追加学習コストが最も低い拡張** |
| **Google しごと検索への対応** | 採用ページの構造化データ対応 |
| **アルバイト・パート媒体**（タウンワーク、バイトル、マイナビバイト 等） | 時給が近隣競合と同等以上であることが前提 |
| **現業・製造特化媒体** | 職種特化型 |
| **地場の折込チラシ・フリーペーパー** | 地方では今も機能する。都市部の感覚で切り捨てない |
| **店頭掲示・のぼり・車両広告** | 通勤圏採用では費用対効果が高い場合がある |
| **紹介予定派遣／派遣からの直接雇用転換** | 定着不安のある職種 |

## 8. 優先6：新卒・若手の札

| 札 | 備考 |
|---|---|
| **逆求人型（オファー型）新卒サービス** | OfferBox、キミスカ、dodaキャンパス 等。無名企業でも接触できる |
| **新卒ナビサイト**（マイナビ、リクナビ） | 知名度と運営体力が前提 |
| **大学キャリアセンター・学内説明会** | 地方大学は中小に協力的な場合がある |
| **研究室・ゼミルート** | 技術系。関係構築に年単位 |
| **合同説明会・逆求人イベント** | 無名企業が対面で不利を相殺できる |
| **インターンシップ** | 選考への情報活用の可否は類型により異なる。要件確認必須 |

## 9. 優先7：既存関係からの転換

| 札 | 備考 |
|---|---|
| **副業・業務委託からの正社員化** | 適合性の確認済み。偽装請負の論点に注意 |
| **派遣スタッフの直接雇用** | 派遣元との契約条項を確認 |
| **再就職支援会社経由** | 通常の紹介より条件が柔軟な場合がある |
| **アルムナイ・出戻り** | 退職理由が解消されているかの確認が前提 |

## 10. スカウト媒体の横展開（既存スキルの転用）

RDS・doda ダイレクトの運用スキルは、以下にそのまま転用できる。**学習コストが低い拡張。**

| 領域 | 例 |
|---|---|
| ハイクラス | ビズリーチ |
| ベンチャー・共感軸 | Wantedly |
| IT・Web | Green |
| エンジニア特化 | Findy、LAPRAS、paiza、forkwell |
| 副業・転職潜在層 | YOUTRUST、Offers |
| 若手 | AMBI 等 |
| グローバル・外資 | LinkedIn |
| アセスメント連動 | ミイダス |

**注意：** 各サービスの現存・料金体系・得意領域は必ず一次確認する。
**この横展開は「工数で買う」札が増えるだけで、金銭を減らす札にはならない**点に注意。

## 11. 増やす順序（現実的な学習計画）

### 第1段階：今日から使える（費用ゼロ・学習コスト最小）
1. 求人票の書き直しの型を作る
2. スカウト文面の型を作る（既存のRDS・dodaダイレクトの返信率が上がる）
3. 求人検索エンジンの横展開（求人ボックス、スタンバイ）
4. 無料の採用ページ作成ツールを1つ触る
5. 高卒採用の年間スケジュールと手続きを調べる

### 第2段階：商談で情報を取りに行く（1〜2ヶ月）
6. スカウト媒体3〜5社の商談を受ける（料金表と得意領域が手に入る）
7. 特化型エージェント3社の商談を受ける
8. アルバイト媒体・現業特化媒体の商談を受ける
9. 助成金の最新要綱を確認し、使える場面を整理する

### 第3段階：関係構築が要る（3〜6ヶ月）
10. 就労移行支援事業所・地域障害者職業センターと接点を作る
11. 登録支援機関・監理団体と接点を作る（外国人採用）
12. 地元の高校・専門学校・職業訓練校のルートを開く
13. 自治体の移住支援・無料職業紹介の窓口を確認する

### 第4段階：設計スキル（継続）
14. リファラル制度設計の型を作る
15. カジュアル面談の設計・運用の型を作る
16. 採用ピッチ資料の作成スキル

## 12. 提案時の組み立て方

手札が増えると「たくさん提案する」誘惑が生まれるが、逆効果になる。

1. **binding constraint を特定する**（`01_母集団形成の手法選定.md` セクション4）
2. **訴求が制約なら、新規費用の発生しない改善から出す**（決裁が要らないので通りやすい）
3. **企業が払える通貨を確認する**（金銭か工数か。両方ないなら要件・条件の見直しが先）
4. **その通貨で払える札を2〜3枚に絞る**
5. **やらない方がいい札とその理由も言う**（説明力の差になる）

> 手札を増やす目的は選択肢を並べることではなく、
> **「この会社にはこれは効かない」と言い切れる範囲を広げること。**
